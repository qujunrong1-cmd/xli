# 采集方法论（Collection Guidelines）

本文件定义心理学知识引擎「采集」环节的方法与质量标准，目标是：**来源权威、证据分级、去污名化、可追溯**。

## 一、权威来源优先级

按可信度从高到低：

1. **国际权威机构**：世界卫生组织 WHO、美国心理学会 APA、美国国家心理健康研究所 NIMH、英国 NHS、中国国家精神卫生相关部门（国家心理健康中心、中国精神卫生调查等）。
2. **同行评审期刊与系统综述**：如 *The Lancet Psychiatry*、*JAMA Psychiatry*、*World Psychiatry*、*Psychological Bulletin* 等。
3. **诊断标准与临床指南**：DSM-5（美国）、ICD-11（WHO）。
4. **政府/学术机构的大型流行病学调查**：如中国首次全国精神障碍流行病学调查（黄悦勤团队，2019）。
5. **知名科普/专业媒体**：如 Verywell Mind、心理学报、丁香医生等（证据等级通常为 D，仅作补充）。

## 二、证据等级判定

| 等级 | 定义 | 举例 |
|---|---|---|
| A | 系统综述 / 元分析 | 多研究汇总的定量结论 |
| B | 随机对照试验（RCT） | 单个高质量干预研究 |
| C | 权威机构指南 / 官方报告 | WHO、APA、NIMH 的立场与数据 |
| D | 专家观点 / 科普 | 单篇科普、专家访谈 |

- 流行病学数据（患病率等）若来自全国性调查，可视为 C（权威报告）。
- 等级越低，回答时越要谨慎措辞，避免当作定论。

## 三、四维度理解法

把任何原始资料拆成四个维度，是「理解」的核心动作：

1. **概念（是什么）**：该术语/现象的定义、诊断标准、典型表现。
2. **机制（为什么）**：生物学（神经递质、基因）、心理学（认知、依恋）、社会（压力、文化）等多层成因。
3. **证据（怎么知道的）**：支持结论的研究、数据、样本与局限。
4. **应用（能做什么）**：可操作的启示——干预方向、预防、自助、就医建议等。

## 四、去污名化与安全底线

- 语言上避免「疯子」「精神病」等歧视性表述；用「患有/经历」替代「是（某种病）」。
- 不输出具体药物剂量、不替代诊断；涉及就医时统一附提示：「以上不能替代专业诊断，如有困扰建议咨询执业精神科医生或心理治疗师」。
- 涉及自杀/自伤相关内容：保持严肃、不做价值判断，优先提供求助资源（如中国心理援助热线）。

## 五、时效性检查

- 心理学诊断标准与流行病学数据会更新，引用时优先 3 年内来源；超过 5 年的关键数据，在「不确定性」中标注时效风险。
- 采集日期必须记录，供后续复查时判断是否「已过时」。

## 六、采集流程清单

1. 确定主题 → 映射到 `knowledge/` 分类目录。
2. 检索权威来源 → 至少 2 个独立来源交叉验证关键数据。
3. 判定证据等级。
4. 四维度拆解 + 提炼要点 + 标注不确定性。
5. 去重检查 → 写卡片 → 更新 `_topics/index.md`。
6. 回读校验：来源、数据、状态字段是否完整。
