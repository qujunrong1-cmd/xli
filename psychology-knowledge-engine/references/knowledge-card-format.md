# 知识卡片格式规范（Knowledge Card Format）

本文件定义心理学知识引擎中「一条知识」的统一记录格式。所有入库知识都必须严格遵循此结构，以保证可检索、可追溯、可去重、可纠错。

## 卡片模板

```markdown
## [卡片标题：一句话概括该知识]

- **状态**：待核实 / 已核实 / 已过时
- **证据等级**：A / B / C / D
- **来源**：[机构/作者]，[标题/报告名]，[年份]，[URL 或文献标识]
- **采集日期**：YYYY-MM-DD

**概念**（是什么）：
[1–3 句，用通俗语言定义或描述]

**机制**（为什么）：
[解释背后的原理或成因；未知则写「尚不明确」]

**证据**（怎么知道的）：
[关键数据、研究结论、样本与方法说明]

**应用**（能做什么）：
[可操作的启示、干预方向或注意事项]

**要点**：
- [≤40 字，一条]
- [≤40 字，一条]

**不确定性 / 争议**：
[数据口径差异、样本限制、地区差异、时效性、学界分歧等；无则写「无」]
```

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 卡片标题 | 是 | 一句话概括，方便索引与去重 |
| 状态 | 是 | `待核实`=初入未验证；`已核实`=经交叉验证；`已过时`=已被新证据取代 |
| 证据等级 | 是 | A 系统综述/元分析；B 随机对照试验；C 权威机构指南；D 专家观点/科普 |
| 来源 | 是 | 至少含机构/作者 + 年份；有 URL 更佳。禁止无来源 |
| 采集日期 | 是 | 用于时效判断 |
| 概念/机制/证据/应用 | 是 | 四维度拆解，是「理解」的落点 |
| 要点 | 是 | 2–5 条，便于快速复用 |
| 不确定性/争议 | 是 | 诚实标注局限，避免过度断言 |

## 去重规则

- 入库前先检索已有主题文件，若新卡片与已有卡片**核心主张相同**，则「合并更新」：补来源、更新数据、追加不确定性，而非新建一条。
- 判定重复看「概念 + 核心结论」是否一致，不看措辞。

## 纠错规则

- 发现某卡片被新证据推翻 → 将「状态」改为 `已过时`，在「不确定性」里注明新证据，而不是直接删除（保留历史追溯）。
- 发现数据有误 → 直接修正并更新「采集日期」。

## 写作约定

- 中文书写，术语首次出现可附英文缩写（如 认知行为疗法 CBT）。
- 数据尽量给具体数字与口径，避免模糊表述（「很多」「较高」要能落到数字）。
- 涉及诊断标准时注明依据（如 DSM-5、ICD-11）。
