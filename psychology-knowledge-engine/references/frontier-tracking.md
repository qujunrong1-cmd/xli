# 前沿追踪方法论（Frontier Tracking）

本文件定义心理学知识引擎「前沿追踪」环节的方法与判断标准，目标是：**跟随学科演进，识别新增/更新/过时，让知识库保持鲜活**。

## 一、追踪什么（范围与优先级）

心理学前沿可分为五类，按对知识库「可操作性」的影响排序：

| 优先级 | 类型 | 示例 | 入库动作 |
|---|---|---|---|
| 高 | 诊断标准变更 | ICD-11 落地、DSM-5-TR 修订 | 更新相关「概念」维度，注明新标准依据 |
| 高 | 权威指南更新 | WHO/APA/NIMH 新指南、立场声明 | 新增或更新卡片，证据等级 C |
| 中 | 重大研究突破 | 顶级期刊的 RCT/元分析新结论 | 新增卡片，证据等级 A/B |
| 中 | 流行病学新数据 | 新全国调查患病率 | 更新旧数据，标记旧卡片时效风险 |
| 低 | 新疗法/新证据 | 数字疗法、新型药物证据 | 新增到 methods/ 或 evidence/ |

## 二、时间窗与检索

- 被动追踪：用户指定主题时，围绕该主题检索「近 1–3 年」进展。
- 主动追踪：检索「近 1 个月（或按调度周期）」的全局进展。
- **必须用 `freshness` 时间过滤**（WebSearch 支持 d/m/y），避免旧闻当新知。
- 检索词建议组合：主题词 + `最新` `进展` `指南` `meta-analysis` `RCT` `更新` `2026` 等。

## 三、比对与分类（核心判断）

读现有 `_topics/index.md` 和相关主题文件后，把每条新信息归为三类：

1. **新增（New）**：知识库里没有的全新主题/结论 → 新建卡片。
2. **更新（Update）**：已有主题有了新数据/新证据 → 合并进对应卡片，更新来源与数据，刷新「采集日期」。
3. **过时（Obsolete）**：旧结论被新证据推翻 → 将旧卡片「状态」改为 `已过时`，在「不确定性/争议」里写清新证据，**不删除**（保留追溯）。

判定口诀：**先查有没有，再看新不新，最后定新/更/废。**

## 四、前沿简报模板

每次追踪结束后，向用户输出简报，结构如下：

```markdown
## 心理学前沿追踪简报（YYYY-MM-DD）

**追踪范围**：<主题或时间窗>

### 本次发现
- [发现1]：<一句话 + 来源 + 证据等级>

### 知识库更新
- 新增：<N> 条（<主题列表>）
- 更新：<M> 条（<主题列表>）
- 标记过时：<K> 条（<主题列表>）

### 建议下一步
- <后续值得关注的方向/主题>
```

## 五、质量与安全底线

- 前沿信息尤其要警惕「标题党」与单一来源：**至少 2 个独立来源交叉验证**再入库。
- 未发表（预印本）、小样本、单一研究 → 证据等级标 D 或 B，并在「不确定性」里注明「初步证据，待更多研究」。
- 涉及新药/新疗法，只描述「研究结论」，不给出任何剂量、适用人群建议；引导咨询执业医生。
- 追踪发现与既有知识矛盾时，优先尊重**更权威、更新、证据等级更高**的来源，同时保留旧条目（标记过时）而非直接覆盖。

## 六、与自动化的配合

- 主动追踪建议做成定时自动化（WorkBuddy 自动化能力），周期 2 周或 1 个月。
- 自动化 prompt 要**自包含**：写明加载本 skill、检索时间窗、比对入库、产出简报四步，不依赖当前会话上下文。
