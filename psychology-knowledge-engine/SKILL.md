# 心理学知识引擎（psychology-knowledge-engine）

## 用途

让 Agent 具备**持续收集、理解、沉淀并检索心理学知识**的能力：把零散、来源不一的心理学科普与研究内容，转化为结构化、可追溯、可复用的知识库，并在后续对话中高效调用。

同时具备**主动追踪心理学最前沿进展**的能力：随着心理学发展，定期检索最新研究、临床指南更新与权威发现，识别「新增 / 更新 / 过时」的知识，让知识库始终保持鲜活，而不是停留在某次采集的静态快照。

> 分类：七、垂直场景与商业 API 类
> 技能类型：知识积累 + 检索
> 风险等级：低-中（知识库可能被错误信息污染）
> 门禁档位：**L1** — 只写本地知识库文件，不涉外部账号与敏感数据；写入前先列影响面。

## 触发条件

- 用户想学习、讨论、检索心理学/心理健康/精神障碍相关知识。
- 用户要求 Agent **持续收集、理解、沉淀新的心理学知识**。
- 用户要求 **追踪心理学最新进展 / 前沿研究**。
- 典型触发词：心理学、心理知识、心理健康、精神障碍、心理疾病、抑郁症、焦虑症、CBT、收集心理知识、学习心理学、心理学前沿、最新研究、追踪进展。

## 何时不要使用

- 医学处方、剂量、诊断建议：**不输出**，引导用户咨询执业精神科医生/心理治疗师。
- 法律意见、司法鉴定：不越权。
- 与心理学无关的请求：交给更合适的技能或直接回答。

## 核心概念：三条铁律

1. **可追溯**：每条知识必须带「来源 + 采集日期 + 证据等级」，禁止无来源断言。
2. **可去重**：入库前先检索知识库，内容重复则合并而非新建。
3. **可纠错**：知识会过时或出错，支持标注 `状态: 待核实 / 已核实 / 已过时`。

## 知识库结构

知识存放在本技能目录 `knowledge/` 下，按主题分文件：

```
knowledge/
├── _topics/                    # 主题索引（单一真相源，登记每个主题文件）
│   └── index.md
├── clinical/                   # 临床与精神障碍（抑郁、焦虑、创伤等）
├── mental-health/              # 心理健康、压力、睡眠、情绪调节
├── theory/                     # 心理学理论与流派（认知、行为、人本等）
├── methods/                    # 干预与疗法（CBT、正念、DBT 等）
└── evidence/                   # 研究证据、流行病学数据、权威调查
```

每条知识按统一「知识卡片」格式记录（见 `references/knowledge-card-format.md`）。

## 标准操作流程

### A. 采集（Collect）
1. 明确用户想了解的主题/问题，定位到 `knowledge/` 下对应分类目录（无则新建，并在 `_topics/index.md` 登记）。
2. 用 WebSearch / domain_search 检索权威来源（优先：WHO、APA、NIMH、中国精神卫生权威机构、同行评审期刊、政府/学术报告）。
3. 判断证据等级：A=系统综述/元分析，B=随机对照试验，C=权威机构指南，D=专家观点/科普。

### B. 理解（Understand）
1. 把原始内容拆成四个维度：**概念（是什么）/ 机制（为什么）/ 证据（怎么知道的）/ 应用（能做什么）**。
2. 提炼 2–5 条可复用的「要点」，每条 ≤ 40 字。
3. 标注不确定性：数据口径、样本限制、地区差异、时效性。

### C. 沉淀（Consolidate）
1. 检索现有知识库，判断是否与已有条目重复；重复则合并更新，不新建。
2. 按 `references/knowledge-card-format.md` 写入一条知识卡片。
3. 更新 `_topics/index.md` 的主题登记（文件名、一句话概述、最近更新日期、条目数）。

### D. 检索（Retrieve）
1. 先读 `_topics/index.md` 定位相关主题文件。
2. 读对应主题文件，提取相关卡片。
3. 引用知识时，**带上来源和证据等级**，并区分「已核实的事实」与「仍有争议的观点」。

## 前沿追踪（Frontier Tracking）

心理学是快速演进的学科：诊断标准、流行病学数据、疗法证据都在持续更新。知识引擎必须**主动跟进**，而不是只等用户提问。

### 追踪范围（什么值得追）

1. **诊断标准变更**：DSM 与 ICD 的修订（如 ICD-11 已落地、DSM-5-TR 更新）。
2. **权威指南更新**：WHO、APA、NIMH 的临床指南与立场声明。
3. **重大研究成果**：发表于顶级期刊（*Lancet Psychiatry*、*JAMA Psychiatry*、*World Psychiatry*、*Psychological Bulletin* 等）的突破性发现。
4. **流行病学新数据**：全国/大规模调查的更新患病率。
5. **新疗法/新证据**：如数字疗法、新型精神科药物的 RCT 与元分析。

### 追踪流程（Run）

1. **定范围**：确定本次追踪的主题或时间窗（如「近 3 个月」「抑郁症相关」）。
2. **检索**：用 WebSearch / domain_search 加 `freshness` 时间过滤，检索上述范围内的最新进展。
3. **比对**：读 `_topics/index.md` 与相关主题文件，判断每条新信息是「新增主题」「更新已有条目」还是「推翻旧结论」。
4. **入库**：新增/更新按 A–D 流程处理；被推翻的旧条目，将「状态」改为 `已过时` 并注明新证据，而非删除。
5. **汇报**：向用户输出一份**前沿简报**——本次发现了什么、哪些知识被更新/标记过时、建议下一步追什么。

### 追踪节奏建议

- 被动触发：用户说「追踪心理学最新进展」时立即执行一次。
- 主动触发（推荐）：建议配合 WorkBuddy 定时自动化，按周/按月自动跑一次前沿追踪并产出简报（见下方「自动化建议」）。

## 外部依赖与前置检查

- 无强制外部依赖；知识库为本地 Markdown 文件。
- 采集新知识、前沿追踪需要网络（WebSearch）；离线时仅能检索已有知识库。
- 详细格式见 `references/knowledge-card-format.md`；采集方法论见 `references/collection-guidelines.md`；前沿追踪方法见 `references/frontier-tracking.md`。
- 知识库统计/检索辅助脚本：`scripts/kb_stats.py`（用法见该文件头注释）。

## 典型使用场景

1. 用户问「抑郁症的常见症状有哪些」→ 检索知识库并回答，缺则采集入库。
2. 用户说「以后持续帮我收集心理学新知识」→ 按采集-理解-沉淀流程，把新知识不断归档。
3. 用户想了解某个心理学流派/疗法 → 定位 theory/ methods 目录，检索并讲解。
4. 用户说「追踪一下心理学最新进展」→ 执行前沿追踪流程，产出简报并更新知识库。

## 使用提示

- 每次采集后都回读校验：关键数据是否在、来源是否保留。
- 定期（或按用户要求）复查知识库，把「已过时」条目标记出来，避免错误信息固化。
- 前沿追踪时务必带时间过滤（`freshness`），避免把旧闻当新知。
- 回答涉及心理健康时，保持温和、去污名化、不贴标签，并视情况附「寻求专业帮助」提示。

## 自动化建议（可选，用于「持续」前沿追踪）

要让前沿追踪真正「持续」跑起来，建议创建一条定时自动化（见 WorkBuddy 自动化能力）。推荐的自动化 prompt（自包含、不含调度信息）：

> 执行「心理学知识引擎」的前沿追踪：加载 psychology-knowledge-engine skill，检索近一个月心理学领域的最新进展（诊断标准、权威指南、重大研究、流行病学新数据、新疗法），与现有知识库比对后更新/新增/标记过时条目，最后输出一份中文前沿简报。

调度建议：每 2 周一次（FREQ=WEEKLY;INTERVAL=2），或按月（FREQ=MONTHLY）。由用户决定是否启用。

## 备注

- 本技能为本地知识引擎，知识库随技能目录持久化，可跨会话复用。
- 心理学信息更新快（诊断标准、流行病学数据会变化），引用数据时优先最新权威来源。
- 通用铁律：先验证现状 → 列影响面 → 取得确认 → 再执行。
